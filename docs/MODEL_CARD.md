# Model card - Touchline explainable models

**Historical training artifact:** the figures below were recorded before the 27 October active-roster simulator fix. The current pipeline evaluation fingerprints the frozen parameters and simulator, but does not rerun calibration or retrain. Do not present these historical model metrics as a fresh evaluation of the corrected generator. Re-evaluate the frozen models on held-out corrected matches before deciding whether to retrain.

The separate [current frozen-model evaluation](FROZEN_MODEL_EVAL.md) measures the unchanged logistic parameters on fresh corrected synthetic matches. Its dataset differs from the historical holdout; it does not isolate the effect of the roster fix or establish real-feed accuracy.

20% of matches are held out for evaluation. No real match data is used.

Intended use: on-screen explanation of synthetic match events. Glass-box by design: every
prediction is decomposed into feature contributions that the Analyst agent must cite.
Limitations: the simulator's own generative assumptions bound what the models can learn;
the hidden 'true' scoring model also uses player finishing skill, which xG deliberately omits
(so finishing over/under-performance is a real, explainable signal).
