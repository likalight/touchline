TOUCHLINE / RESEARCH KIT

Can people follow the story?

A ten-minute, moderated test. This file starts blank and does not send data anywhere. Download each consenting participant’s anonymous observations. Do not enter names, email addresses or recordings.

Before the test

Say: “This is a fictional match with made-up clubs. We’re testing the app, not you. Please think aloud. You can stop whenever you want. May I keep anonymous notes about how the tasks go?”

Keep the task order. Start timing after reading the task. Allow 90 seconds before offering help; record assistance. Do not explain where a control is before the participant tries.

Observed tasks

Ask afterwards

How to report the results

Recruit 3–5 consenting people if possible. Report “n of N completed without help” for each task, median observed time, recurring problems and the fixes made. Include failures. This convenience sample does not establish population-wide impact, broadcaster adoption or accessibility certification. Automated browser tests are separate evidence.

For a producer session, separately compare time to review a cue, corrections required and whether they would accept it in a preview workflow. Do not claim on-air readiness from this session.
